# College Event Management System

## Project Overview

The College Event Management System is a responsive web application developed using HTML, CSS, and Bootstrap. It allows students to view upcoming events, register for events, check event schedules, browse event galleries, access FAQs, and contact event coordinators.

## Features

### Home Page
- Responsive Navigation Bar
- Hero Section
- Event Highlights
- Register Now Button

### Events Page
- Event Cards
- Event Images
- Event Date and Venue Information
- Registration Buttons

### Registration Page
- Student Registration Form
- Event Selection Dropdown
- Registration Success Message

### Schedule Page
- Responsive Event Schedule Table
- Table Striped and Hover Effects

### Gallery Page
- Responsive Image Gallery
- Card-Based Layout

### FAQ Page
- Accordion-Based FAQ Section

### Contact Page
- Contact Form
- Coordinator Information
- Social Media Links

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5

## Responsive Design

The website is fully responsive and adapts to different screen sizes including desktop, tablet, and mobile devices.

## Purpose

This project demonstrates the use of Bootstrap components such as navigation bars, cards, forms, tables, accordions, responsive grids, and utility classes to build a modern multi-page web application.
